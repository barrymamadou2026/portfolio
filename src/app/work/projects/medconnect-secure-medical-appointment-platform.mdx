## The Problem

MedConnect addresses the need to manage medical appointments through a secure application for patients and healthcare providers.

## My Role

Backend development.

## How It Was Designed

The application uses a Spring Boot backend, JWT-based authentication and authorization, and a MySQL database. Render and Vercel were used for deployment.

## Technical Implementation

- Spring Boot backend
- JWT authentication and authorization
- MySQL database
- Secure access management

## Deployment

- Render
- Vercel

## Technical Challenges Addressed

- Protecting access through JWT authentication and authorization
- Integrating backend services with a MySQL database
- Deploying the application using Render and Vercel

## What I Learned

- Backend architecture
- Authentication
- Database integration
- Cloud deployment
- Team development
