## The Problem

Design a local-area network for a university environment, including an addressing and segmentation plan that could be simulated and documented.

## My Role

Network design, simulation and technical documentation.

## How It Was Designed

The design covered network architecture, IP addressing and VLAN segmentation, then used Cisco Packet Tracer to simulate the network.

## Work

- Network architecture design
- IP addressing
- VLAN segmentation
- Network simulation
- Technical documentation

## Tools

Cisco Packet Tracer, TCP/IP and VLAN concepts.

## Technical Challenges Addressed

- Planning IP addressing for the proposed network
- Separating network segments with VLANs
- Documenting a design that could be reviewed alongside its simulation

## What I Learned

- Network architecture
- Segmentation
- IP addressing
- Technical documentation
