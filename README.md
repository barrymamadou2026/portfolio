## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## Build

Run the production build with:

```bash
npm run build
```

Start the production server with:

```bash
npm run start
```

TypeScript can be checked with:

```bash
npx tsc --noEmit
```
